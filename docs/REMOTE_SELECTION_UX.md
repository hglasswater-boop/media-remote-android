# Controller playlist UX

The intended fast path is:

1. Pair once by scanning the playback phone's QR.
2. On the controller phone, tap `YouTube Musicのプレイリストを開く`.
3. Choose a playlist in YouTube Music.
4. Tap Share and select MediaRemote.
5. MediaRemote switches to controller mode and forwards the shared URL to the stored playback phone.

A manual song/search field remains available as a fallback.
